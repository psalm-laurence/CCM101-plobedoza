# Mission Reflection
# 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the compute resource is one of the most important cloud infrastructure components because it is responsible for running applications, programs, and services. Without compute resources, the other components would not be able to support an application properly.

# 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. I used Linux in KillerCoda to check the CPU, memory, storage, network information, and other resources of the cloud environment.

# 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand what resources are available and how they should be used. It also makes it easier to plan, troubleshoot, maintain, and explain the infrastructure to other team members.

# 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using different commands. I also learned how to identify compute, storage, networking, and operating system resources. I improved my skills in creating Markdown documentation, researching cloud providers, and designing a simple cloud infrastructure diagram.

# 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and useful because I added my second laboratory activity. It now contains technical reports, cloud provider comparisons, documentation, screenshots, and an architecture diagram. This helped me understand how GitHub can be used to keep my cloud computing activities and projects in one organized portfolio.
