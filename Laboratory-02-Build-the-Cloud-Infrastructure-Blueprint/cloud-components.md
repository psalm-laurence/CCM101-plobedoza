##Compute Resources
#The CPU provided by the KillerCoda Linux environment represents the compute resource used to execute commands and applications.

##Storage Resources
#The disk and mounted filesystems available in the Linux environment represent storage resources.

##Networking Resources
#The IP address and network interface allow the KillerCoda server to communicate with other systems over a network.

##Operating System
#Ubuntu Linux manages the resources of the KillerCoda environment and provides the command-line interface used during the laboratory.
