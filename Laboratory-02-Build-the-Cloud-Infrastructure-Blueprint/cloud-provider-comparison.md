# Cloud Provider Comparison

## Comparison of Major Cloud Providers

| Infrastructure Component                 | AWS                       | Microsoft Azure                 | Google Cloud Platform (GCP) |
| ---------------------------------------- | ------------------------- | ------------------------------- | --------------------------- |
| **Compute**                              | Amazon EC2                | Azure Virtual Machines          | Google Compute Engine       |
| **Storage**                              | Amazon S3                 | Azure Blob Storage              | Google Cloud Storage        |
| **Networking**                           | Amazon VPC                | Azure Virtual Network           | Google Cloud VPC            |
| **Identity and Access Management (IAM)** | AWS IAM                   | Microsoft Entra ID / Azure RBAC | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers a very broad range of cloud services. It provides many options for computing, storage, networking, databases, security, analytics, and other cloud technologies.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with many Microsoft products and services. Organizations that already use Microsoft technologies can benefit from its integration with the Microsoft ecosystem.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its AI and Machine Learning services and its strong connection to Kubernetes technology. Google also provides services that make it easier for organizations to build and deploy AI and containerized applications.

### 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar basic infrastructure services. All of them provide compute, storage, networking, and identity and access management services, although they use different names and features for these services.
