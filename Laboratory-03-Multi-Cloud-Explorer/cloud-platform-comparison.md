## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely known for offering a very broad range of cloud services. It provides services for computing, storage, databases, networking, security, analytics, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best choice for organizations that mainly use Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is well known for its artificial intelligence and machine learning capabilities and its strong connection to Kubernetes. Google originally developed Kubernetes, which is now widely used for managing containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Microsoft Azure because it provides many useful services and has strong integration with Microsoft technologies. I also find its services useful for organizations that already use Windows and Microsoft products.
