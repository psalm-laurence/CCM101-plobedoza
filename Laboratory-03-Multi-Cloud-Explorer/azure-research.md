# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, artificial intelligence, and other business requirements.

## Global Infrastructure

Azure provides a global infrastructure made up of regions and availability options that allow organizations to deploy services in different geographic locations.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services

### 1. Azure Virtual Machines

Provides virtual machines for running applications and workloads.

### 2. Azure Blob Storage

Provides object storage for files, documents, backups, and other unstructured data.

### 3. Azure Virtual Network

Provides networking capabilities for Azure resources.

### 4. Microsoft Entra ID

Provides identity and access management for users and applications.

## Three Advantages

- Strong integration with Microsoft products
- Enterprise-focused services
- Global cloud infrastructure

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows workloads, databases, identity management, Microsoft 365-related environments, AI, and hybrid cloud solutions.
