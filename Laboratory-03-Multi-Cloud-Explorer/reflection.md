# Reflection

In this laboratory activity, I learned more about the three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Each checkpoint helped me understand how cloud platforms are used and how to choose the right platform based on a client’s needs.

In **Checkpoint 1**, I created the folder and Markdown files for the Multi-Cloud Explorer activity in my GitHub repository. This helped me organize my files and prepare the documents for the succeeding checkpoints. In **Checkpoint 2**, I researched AWS, Azure, and GCP using their official websites and learned about their global infrastructure, management consoles, core services, advantages, and common enterprise uses.

In **Checkpoint 3**, I compared the three cloud platforms based on their services, strengths, and ideal users. I learned that AWS has a broad range of services, Azure has strong Microsoft integration, and GCP is strong in AI, Machine Learning, and Kubernetes. In **Checkpoint 4**, I recommended cloud platforms for different clients. For example, I chose Azure for the university because of its Microsoft environment, GCP for the AI research company, and AWS for the global e-commerce company.

In **Checkpoint 5**, I compared similar services such as virtual machines, storage, identity management, databases, and Kubernetes. This helped me understand that different providers can offer similar services but with different features. In **Checkpoint 6**, I matched business requirements with the most suitable cloud platform.

For **Checkpoint 7**, I used KillerCoda and Linux commands to check the operating system, CPU, memory, and disk. This gave me a better understanding of the resources that can also be provided by cloud platforms. Finally, in **Checkpoint 8**, I reflected on what I learned and how GitHub helped me organize my work.

Overall, this activity taught me that choosing a cloud provider depends on the client’s needs, budget, existing technology, and future plans. It also improved my research, documentation, Linux, and GitHub skills.
