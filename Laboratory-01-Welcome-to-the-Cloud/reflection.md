# Reflection

This laboratory activity helped me learn the basics of using a cloud-based Linux environment through KillerCoda. I learned how to create a new Linux user, log in using the account, and use basic Linux commands to check system information such as the operating system, kernel, CPU, memory, and disk space.

I also learned how to create and organize files and folders using Linux and document my work using Markdown. Creating my GitHub repository helped me understand how I can use GitHub to organize and present my laboratory activities.

At first, some of the Linux commands were unfamiliar to me, but I became more comfortable as I practiced them. Overall, this activity gave me a better understanding of Linux, cloud computing, and the importance of properly documenting my work.
