 # Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory introduced me to a cloud-based Linux environment using KillerCoda. I learned how to access a Linux playground, create and manage a user account, investigate system information, organize files and directories, and document my work using Markdown.

## Objectives

- Access a cloud-based Linux environment.
- Create and manage a Linux user.
- Explore basic Linux system information.
- Create files and directories using Linux commands.
- Practice Markdown documentation.
- Create and manage a GitHub repository.

## Activities Performed

- Launched an Ubuntu Linux Playground using KillerCoda.
- Created a new Linux user with Bash, a home directory, and sudo privileges.
- Logged in using the newly created account.
- Collected information about the Linux distribution, kernel, CPU, memory, and disk space.
- Created the required directory and file structure.
- Created Markdown documentation.
- Created a public GitHub repository.
- Prepared screenshots as evidence of completed activities.

## Skills Learned

Through this laboratory, I learned how to work with a cloud-based Linux environment, manage users, navigate the Linux filesystem, collect system information, create Markdown files, organize a project directory, and prepare a GitHub repository for documenting cloud computing activities.
