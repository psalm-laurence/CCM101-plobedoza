# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their assigned tasks. It is important in cloud environments because it reduces the risk of unauthorized access, accidental changes, and damage if an account is compromised.

## 2. Attack Surface

An attack surface is the collection of possible entry points that an attacker could use to access or exploit a virtual machine. These entry points may include open network ports, running services, exposed applications, and accounts with weak security. Reducing unnecessary entry points makes the server harder to attack.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual hackers because unknown or new sources are also blocked unless they have permission to access an allowed service.
